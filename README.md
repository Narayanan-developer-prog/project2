# QR Code Generator

A simple and responsive QR Code Generator built using **Flask, HTML, CSS, and JavaScript**. This web application allows users to generate QR codes from any text or URL and download them as PNG images.

## 🚀 Live Demo

**Live Website:** https://project2-p7b2.onrender.com

## 📂 GitHub Repository

Replace this link with your repository URL:

```text
https://github.com/Narayanan-developer-prog/project2
```

## ✨ Features

* Generate QR codes from any text or URL
* Download generated QR codes as PNG images
* Clean and responsive user interface
* Fast QR code generation using a QR Code API
* Built with Flask backend

## 🛠️ Technologies Used

* Python
* Flask
* HTML5
* CSS3
* JavaScript
* Gunicorn (for deployment)
* Render (Hosting)

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Narayanan-developer-prog/project2.git
```

Go to the project folder:

```bash
cd project2
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```

## 📸 How to Use

1. Open the application.
2. Enter any text or URL.
3. Click **Generate QR Code**.
4. View the generated QR code.
5. Click **Download QR Code** to save it.
